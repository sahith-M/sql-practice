# sql-practice

My SQL training log for a data analyst / data engineer transition, built on public New York State hospital data.

- `sparcs_questions.sql`: business questions answered on the SPARCS 2023 de-identified inpatient discharge file (about 2.1 million stays)
- `problems/`: weekly log of interview-style SQL problems
- `setup/`: scripts that load the raw CSV into PostgreSQL (raw TEXT table, then a typed `sparcs.discharges` table)
- `sql/`: SQL generated by the loader

## Load the data (Windows)

1. Install PostgreSQL (remember the password) and DBeaver.
2. Download the CSV from [Health Data NY: Hospital Inpatient Discharges (SPARCS De-Identified): 2023](https://health.data.ny.gov/Health/Hospital-Inpatient-Discharges-SPARCS-De-Identified/46xm-urtu) and save it as `data/sparcs_2023.csv`.
3. Open Anaconda Prompt, `cd` into this folder, run `setup\load_sparcs.bat`.
4. The last step prints two row counts (raw and clean). They must match.

Why two tables: the raw table loads every value as text, so the load never fails on a bad value. The clean table
turns empty strings into NULL, strips commas and `$` from numbers, and turns values like `120 +` into 120 with a
`_capped` flag. Codes and IDs (facility ID, DRG code, ZIP) stay text: they are labels, not quantities.
